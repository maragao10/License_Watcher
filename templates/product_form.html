Consultas de licença

Cada consulta é uma chamada GET. O campo "lista" é o caminho até a lista no JSON (ex: entry ou response.items; vazio se a resposta já é a lista); "nome" e "expira" são caminhos dentro de cada item (ex: content.expiration_time). Datas ISO, dd/mm/aaaa ou epoch são aceitas. Para um mesmo produto com várias licenças em endpoints diferentes (ex: Splunk Enterprise e ITSI), adicione uma consulta por endpoint.
No vCenter não há consultas a configurar: o app lê todas as licenças direto pela API do vSphere. Informe a URL (ex: https://vcenter.seudominio.com), um usuário somente leitura e a senha.

Licenças (cadastro manual)

Para produtos sem API de licença (ex: ThousandEyes). Informe o nome da licença e a data de vencimento; elas entram no Dashboard e no alerta do Webex como as outras. Quando renovar, volte aqui e atualize a data.
